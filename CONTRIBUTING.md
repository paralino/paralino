# Contributing to Paralino

Thank you for checking out Paralino and your interest in contributing! If you have any questions before getting started, please reach out to us at **support@paralino.com**.

ℹ️ **Due to a tightly planned roadmap and limited engineering resources, we are not accepting external Pull Requests (PRs) at this stage.**

Paralino Android and iOS apps are open-source for the purpose of providing trust and transparency into the inner workings of the project.

## 💬 How You Can Contribute

### 1. Submit Bug Reports
If you encounter a crash, unexpected behavior, UI glitches, performance degradation, or any other annoyances, please let us know!
* Search existing issues to ensure it hasn't already been reported.
* Alternatively, you can check and open an issue on our [feedback portal](https://portal.paralino.com).
* If it's a new issue, use the [Bug Report Template](https://github.com/paralino/paralino/issues/new?template=bug_report.yaml) to create a bug report. Provide as much detail as possible, including system specifications and steps to reproduce.

To make sure the issue is still present in the latest version, please also check the [release notes](https://github.com/paralino/paralino/releases) for the latest release.

### 2. Suggest Features & Enhancements
Do you have an idea for a feature that would make Paralino better or improve an existing one? Open an issue using our [Feature Request Template](https://github.com/paralino/paralino/issues/new?template=feature_request.yaml), or share your feedback through our [feedback portal](https://portal.paralino.com). When you do, explain the problem you want to solve or the value the feature would bring to Paralino users.

### 3. Share Feedback and Ask Questions
Have questions about how Paralino works, how to use it, or just want to share your thoughts?
Feel free to engage on GitHub Discussions, check out our [feedback portal](https://portal.paralino.com), or open an issue under general feedback.
