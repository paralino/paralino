# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

If you believe you have discovered a security issue in Paralino, please reach out to **security@paralino.com** so we can address it before it is disclosed publicly.
 
We will acknowledge receipt of your vulnerability report within 2 working days and will work diligently to investigate and coordinate a patch.

We actively support and patch the latest app version, so please upgrade to the latest official release before creating a report. Please do not report issues affecting only older versions.

We already run automated and AI-assisted security scanning on every major release and triage findings internally. Please do not submit raw tool output, duplicate findings, or out-of-scope issues. We welcome verified vulnerability reports with clear reproduction steps and impact.
